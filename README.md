**1. System requirements**

- This code has been written using R v4.3.0. 
- Packages used include: dplyr (v1.1.4), tidyr (v1.3.1), stats (v4.5.2), data.table (v1.17.8), purrr (v1.1.0), emmeans (v2.0.4), MASS (v7.3-65), car (v3.1-3), rstatix (v0.7.3), broom (v1.0.11)

**2. Installation & use**

- Download these scripts (statistical_analysis.R; longitudinal_analysis.R) and run through terminal or on RStudio.

**3. Demo**

- Instructions to run on data: Ensure "dummy_data.csv" and "dummy_long_data.csv" are located in the same directory as their respective scripts.
- Expected output for both statistical and longitudinal analyses: "expected_output.txt"
- Expected run time for demo on a “normal” desktop computer: 30-45 minutes
